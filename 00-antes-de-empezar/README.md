# Paso 0 — Antes de empezar

## Qué es un `.md`

Este archivo que estás leyendo es Markdown (`.md`): texto plano con símbolos
simples (`#` para títulos, `**negrita**`, listas con `-`) que GitHub y muchas
herramientas convierten en texto formateado. No necesita un programa especial,
cualquier editor de texto lo abre.

## Qué es un README

Un `README.md` es el primer archivo que alguien lee al entrar a un proyecto.
Responde: ¿qué es esto?, ¿cómo lo instalo?, ¿cómo lo uso? El [README.md de la
raíz](../README.md) de este repo responde eso para todo el proyecto. Este
archivo responde lo mismo, pero solo para este paso.

## Qué es una skill (en el contexto de IA)

Una skill es un paquete de instrucciones que le das a un asistente de IA
(como GitHub Copilot) para que sepa hacer una tarea específica sin que tengas
que explicársela de cero cada vez, por ejemplo "cómo desplegar este sitio" o
"cómo generar una página nueva siguiendo nuestro estilo". En el Paso 3 vas a
ver una en acción.

## Qué necesitas instalado

- **Node.js** (v20.9 o más reciente; ojo, no v18, Next.js 16 no corre ahí).
  Corre `node -v` en la terminal para verificar. Si no lo tienes o tienes
  una versión vieja, descárgalo de [nodejs.org](https://nodejs.org).
- Un editor de código: **VS Code**, con la extensión de **GitHub Copilot**
  instalada y tu cuenta de GitHub conectada (plan Copilot Free).
- Nada de pago, nada de API keys para este taller.

## Prework: haz esto antes del día del taller

La lista paso a paso, para Windows y Mac, está en
[`../PREWORK.md`](../PREWORK.md). En resumen:

1. Instala Node.js, VS Code y la extensión de Copilot.
2. Clona este repo y corre `npm install` adentro (pesa unos 300 MB).
3. Haz los ejercicios de los pasos 01 y 02 (son prework, no se hacen en vivo).
4. Busca y guarda una **imagen de referencia** (Pinterest u otra fuente) del
   estilo visual que te gustaría para tu sitio. Es obligatoria: el agente te
   la va a pedir en el Paso 3.
5. Envía una captura de pantalla a Jair o Alannis para confirmar que todo
   corre.

Si algo no te funciona, no pasa nada: avisa antes del taller y Alannis te
ayuda. Los problemas comunes están en
[`../SOLUCION_DE_PROBLEMAS.md`](../SOLUCION_DE_PROBLEMAS.md).
